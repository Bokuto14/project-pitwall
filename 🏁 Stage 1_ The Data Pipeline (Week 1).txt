🏁 Stage 1: The Data Pipeline (Week 1)
Goal: Get clean data for a single race (e.g., Bahrain 2024) and display the actual lap times.
* Task A (You): Write a script to fetch LapTimes for a specific race using FastF1. Filter out "Safety Car" laps (outliers).
* Task B (Friend): Clean the data. Convert "1:32.450" (string) into 92.45 (float seconds). Handle missing data (NaNs).
* Antigravity Prompt: "Create a Python class DataManager that uses FastF1 to load the 2024 Bahrain GP. Return a cleaned Pandas DataFrame with columns: Driver, LapNumber, LapTime (seconds), Compound."

🛞 Stage 2: The Physics Engine (Week 2)
Goal: Create the math model that predicts how tires slow down over time.
* Task A: Implement a Linear Degradation Model.
   * Equation: $LapTime_{pred} = BasePace + (DegPerLap \times LapAge) - (FuelBurn \times LapNumber)$
* Task B: Calculate the "Pit Loss" constant (how much time it takes to drive through the pit lane at that specific track).
* Antigravity Prompt: "Write a function that calculates the average tire degradation per lap for Hard, Medium, and Soft tires based on the first 10 laps of a stint."

🔮 Stage 3: The "What-If" Logic (Week 3)
Goal: The core feature. Stitching the real data with your simulated data.
* Task A: Build the simulate_strategy(driver, pit_lap, new_compound) function.
   * Logic: If the user changes the pit stop to Lap 20, keep actual data for Laps 1-20, then generate predicted data for Laps 21-57 using the engine from Stage 2.
* Task B: Merge this "Virtual Driver" back into the main dataset to compare with rivals.
